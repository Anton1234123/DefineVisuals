# Define Visuals

**Define Visuals** is a client-side visual enhancement and HUD utility mod for Minecraft 1.21.4 (Fabric).

## ✨ Features

- 🎨 **Modern Liquid Glass UI**: Clean and customizable ClickGUI menu with smooth blur, animations, and custom shaders.
- 📊 **Customizable HUD Elements**: Watermark, ArrayList, TargetHUD, Armor & Potion status, TPS, and Coordinate displays.
- 🖼️ **Interactive Title Screen**: Multi-background manager with smooth crossfades and parallax effects.
- 📅 **Server Events Tracker (HolyEvents)**: Integrated in-game tracker with automated fast anarchy switching.
- ⚙️ **Theme System**: Pre-built & custom color themes with dynamic palette accenting.

## 🛠️ Building from Source

### Prerequisites
- JDK 21+
- Git

### Build Instructions
`ash
# Clone the repository
git clone https://github.com/USERNAME/DefineVisuals.git
cd DefineVisuals

# Build the mod JAR
./gradlew build
`
The compiled mod JAR will be located in uild/libs/definevisuals-1.0.0.jar.
