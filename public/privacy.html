Privacy Policy

Обновлено: 6 ноября 2026

Что мы собираем / What we collect

Cloud по умолчанию не обращается к серверу. Только после явного согласия в Modern Menu → Configurations → Cloud клиент отправляет минимальный набор данных, необходимый для каталога и облачных конфигов:

  • Случайный ID (например, DV-8F3K-2M9Q-71XA-B4CD) — генерируется после согласия и хранится локально в файле define/cloud.json. ID не привязан к железу и не кодирует идентификаторы устройства.
  • Ник Minecraft — публичное игровое имя.
  • Версия клиента и время запусков.
  • Конфиги, которые ты сам добровольно загружаешь в облако.

Cloud makes no server requests by default. After explicit opt-in, the client sends a random ID (stored locally in define/cloud.json, not tied to hardware), your public Minecraft username, client version, launch timestamps, and only the configs you voluntarily upload.

Чего мы НЕ собираем / What we never collect

  • Пароли, токены сессии Minecraft/Microsoft, почту — никогда.
  • HWID, серийные номера железа, данные о компьютере.
  • IP-адреса не хранятся в базе в открытом виде: для rate limit сохраняется только односторонний хеш IP с солью.
  • Никакой скрытой телеметрии и сторонних трекеров.

Как отключиться / Opt-out

Открой Configurations → Cloud → Правила → Отозвать согласие. После этого клиент перестанет выполнять Cloud-запросы; остальные функции Define Visuals продолжат работать офлайн. Согласие версионируется и хранится только локально в define/cloud.json.

Удаление данных / Data deletion

Свои конфиги можно удалить прямо в Cloud-каталоге кнопкой корзины. Для удаления записи профиля напиши в Issues репозитория и приложи свой Cloud ID. Не публикуй ID в открытом сообщении, если не хочешь передавать ключ управления конфигами.

Цель и основание обработки / Purpose and basis

Данные используются только для статистики комьюнити, отметки автора и управления облачными конфигами. Основание — добровольное согласие, которое можно отозвать в любой момент. Мы не продаём данные и не используем их для рекламы или профилирования.

Условия использования Cloud / Terms of Use

  • Загружая конфиг, ты подтверждаешь, что вправе им делиться, и разрешаешь Define Visuals хранить и публично распространять его через каталог.
  • Не загружай пароли, токены, персональные данные, вредоносный контент или материалы, права на которые тебе не принадлежат.
  • Публичными становятся название конфига, ник автора, дата, число скачиваний и содержимое самого конфига.
  • Мы можем удалить контент, нарушающий правила или безопасность сервиса. Cloud предоставляется «как есть» и может временно быть недоступен.
  • Нажатие «Принять и продолжить» в клиенте означает принятие этих условий и Privacy Policy текущей версии.
